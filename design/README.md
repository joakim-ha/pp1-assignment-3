# Design (del A)

Lägg din design här **innan** du skriver någon kod, och checka in den. Det finns inget givet kontrakt: designen omfattar enheterna, förmågorna, hemmet, scenarierna och åtgärderna.

| Fil | Innehåll |
|---|---|
| `analysis.md` | Finns redan med rubriker. Under rubrikerna för genomspelningarna skriver du några meningar om vad som händer när Godnatt körs och vilka klasser som tillkommer när persiennen läggs till. Substantiv- och verbanalysen gör du som stöd för klassdiagrammet, men den lämnas inte in. |
| `../uml/design.asta` eller `../uml/design.mmd`, och `../uml/design.png` | Det inledande klassdiagrammet från Astah eller Mermaid, med paketet för varje klass |

CRC-kort från F07 kan hjälpa när du spelar igenom Godnatt, men de behöver inte lämnas in.

Om koden senare avviker från designen beskriver du det i `deviations.md`.
